## O que é

Uma escola conceitual de educação infantil em contexto nordestino, construída
por script Python no Blender e exportada como `GLB` para navegação em primeira
pessoa no navegador via Three.js.

O objetivo é demonstrar, de ponta a ponta:

- modelagem procedural de arquitetura escolar;
- exportação GLB com hierarquia e colisores preservados;
- aplicação Web estática sem build (ES modules + import map);
- navegação FPS com colisão AABB;
- portas automáticas por proximidade;
- rotas de acessibilidade e marcadores informativos.

|---|---|

## Funcionalidades

- **Navegação FPS** com delta time e movimentação diagonal normalizada.
- **Colisão** por AABB 2D contra colisores extraídos do GLB (`COLLIDER_*`).
- **Portas automáticas** por proximidade, com pivô + folha independentes.
- **8 rotas** de acessibilidade (`ROUTE_001` … `ROUTE_008`), com estados
  `OK` / `INTERRUPTED` visíveis por cor.
- **8 marcadores**, **4 obstáculos** e **3 perigos** posicionados no modelo.
- **HUD de ambiente** — reconhece o espaço atual por bounding box.
- **Minimapa esquemático** (não técnico) com jogador, rota e origem/destino.
- **Modo Exploração** e **Modo Análise**.
- **Painel de camadas** — arquitetura, rotas, marcadores, obstáculos, perigos.
